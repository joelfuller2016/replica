# AIApply public heading trial — 2026-11-08

## Scope and source

This is a bounded live trial of the fixed Replica CLI at commit `7eb4c1a092f4797dac3a34dfcaea947c98e37f95` on branch `fix/windows-and-comparison-gates`. The public target was `https://aiapply.co/`, scoped to the observed homepage H1 `#lp-header-h1` with text “Stop Applying for Weeks Start Interviewing in Days”. A two-request anonymous raw-HTTP preflight returned HTTP 200 both times and the same page title, `Job Application AI with Auto Apply | AIApply`; the HTML and linked CSS were also reachable. The CLI reference capture then found the selected H1 in its blueprints at both requested viewports, with a visible nonzero root and the expected text.

The scope covers the public heading only. It does not establish a whole-site rebuild or product acceptance. No login, account, form, ATS, job-application or payment flow was opened. The CLI ran in fresh Chromium contexts without `--storage`; no preflight cookie or authenticated browser state was supplied. Raw captures, blueprints, comparison sheets and the synthetic fixture remain under ignored `.replica/aiapply-trial/` and are not included in Git.

## Commands and environment

Commands were run from the fork root in PowerShell 7.6.5:

```powershell
node skills/replica/scripts/replica.mjs capture 'https://aiapply.co/' --out '.replica/aiapply-trial/ref' --selector '#lp-header-h1' --viewports '1440x900,390x844' --motion 0
# exit 0

node skills/replica/scripts/replica.mjs compare '.replica/aiapply-trial/ref' 'https://aiapply.co/' --out '.replica/aiapply-trial/repeat-live'
# exit 0

node skills/replica/scripts/replica.mjs compare '.replica/aiapply-trial/ref' '.replica/aiapply-trial/mismatch.html' --out '.replica/aiapply-trial/negative-control'
# exit 1, NOT YET
```

At each capture/compare checkpoint the fork status was clean. Separate collaborator documentation changes appeared during report preparation and were preserved without modification. `git check-ignore -v` confirmed `.replica/aiapply-trial/` is ignored.

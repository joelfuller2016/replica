## Findings and correction sequence

At the upstream baseline, `test/selftest.mjs` formed local paths with `URL.pathname`, which turns a Windows file URL into a path Node cannot resolve. The original preflight observed a `C:\C:\...` path and `MODULE_NOT_FOUND`. I spot-checked the baseline with `git show 6e79299:skills/replica/scripts/test/selftest.mjs`; the CLI and fixture paths used `.pathname`.

An image reference at `structure` has no layout or motion metric to gate. The baseline scored an empty gate list vacuously, then passed a null overall score to report formatting; the observed result was a `null.toFixed` error, not a valid PASS. With the guard removed, the compare CLI emitted the `null.toFixed` crash and exited 2; the regression runner correctly went red with exit 1 because it expected the no-gate diagnostic. The post-mutation regression and direct CLI checks below verify that the restored guard exits 2 before writing any round, history, or custom-output artifact.

For URL references, a canvas can visibly animate without any DOM motion tracks. The baseline URL path returned `scoreTracks(...)`; with no tracks on either side that function returns 100, while the already measured raster frames did not affect the URL motion score.

The final implementation uses `fileURLToPath` for self-test fixtures and the browser-install hint. It checks that at least one metric intersects the selected level gates before creating a comparison round or history entry. The unchanged gates are structure 90/85, faithful 95/95/85/90, and exact 98/98/97/95. The raster fallback applies only when both URL motion track arrays are empty; it downsamples whole frames to a maximum dimension near 1000 pixels, then scores spatial change overlap and signed brightness direction. The per-pixel activity threshold is lower to retain small gradual changes; the configured score gates are unchanged.

## Scope and remaining limits

Raster fallback currently runs only when both reference and clone have no DOM motion tracks. It compares downsampled change footprints within one sample pixel and the sign of brightness change; it is not optical flow or a general test of mixed DOM-to-canvas implementations. The direction control is a deterministic synthetic fade. The anonymous AIApply live-site trial, including repeat variance and a negative synthetic control, belongs to the separate trial worker and is not established by these checks.

No app-server or CLI process started for these checks remains running. All raw test and protocol artifacts are local under the ignored `.replica/` directory.
